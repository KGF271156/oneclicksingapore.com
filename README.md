# OneClick Singapore

Draft diaspora site for Singapore (static HTML, GitHub Pages), part of the OneClick network.

- 5 regions with maps (URA region boundaries), news feeds (`data/news/`), Makan, Lobang, Toolkit, Culture, Events, Communities and a Visit Singapore itinerary form.
- English only for now; a Chinese / Malay / Tamil switch can be added using the same mechanism as OneClick France.
- Itinerary form webhook: set `WEBHOOK_URL` in `js/itinerary-form.js`.
- Domain: oneclicksingapore.com (see `CNAME`).
